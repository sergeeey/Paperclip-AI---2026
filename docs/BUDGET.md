# Budget — BlindSpotSec

**Цель:** не выйти за рамки компанейского бюджета Paperclip и отслеживать фактический burn.

## Целевые лимиты (из README)

| Уровень | USD / мес |
|---------|-----------|
| Компания (safety cap) | $450 |
| CEO | $100 |
| Scanner | $300 |
| Reporter | $200 |

Сумма агентов может превышать cap компании намеренно: срабатывает остановка на уровне компании.

## Учёт

- В UI Paperclip: Costs & Budgets по агентам.
- **Ограничение:** при подписке Codex стоимость может отображаться как `0`; дублируйте контроль по дашбордам OpenAI / лимитам токенов вручную до исправления платформы.

## Действия при превышении

1. Выявить агента с максимальным расходом.
2. Уменьшить Pulse, scope задач или приостановить агента.
3. Зафиксировать инцидент в `.paperclip/memory/activeContext.md`.
