# Access Reference — где хранить учётные данные

**Назначение:** описание **типов** секретов и **мест хранения**. Значения ключей в этот репозиторий не помещаются.

---

## Приоритет хранения

| Метод | Когда использовать |
|-------|-------------------|
| Менеджер паролей (1Password, Bitwarden) | Основной вариант |
| Paperclip UI → Secrets (Seal / dropdown) | Production для агентов |
| Локальный `.env` | Скрипты на вашей машине; в `.gitignore` |
| age / ansible-vault | Зашифрованный бэкап `.env` (опционально) |

---

## Сервер (VPS)

- **IP / hostname:** только в личных заметках или vault, не в git.
- **SSH:** ключ `~/.ssh/…`, `ssh-copy-id`; по возможности отключить вход по паролю для root.

```bash
ssh -i ~/.ssh/your_key root@YOUR_VPS_IP
```

---

## API (имена переменных)

| Переменная | Назначение |
|------------|------------|
| `ANTHROPIC_API_KEY` | Claude / Scanner |
| `OPENAI_API_KEY` | OpenAI / Codex (если используется API) |
| `GOOGLE_API_KEY` | Gemini (если используется в вашей конфигурации) |
| `BRAVE_SEARCH_API` | Поиск / обогащение |
| `RESEND_API_KEY` | Почта |
| `GITHUB_TOKEN` | Клонирование приватных репозиториев |

Проверки валидности — через официальные endpoint’ы провайдеров; не логируйте ключи.

---

## ID инстанса Paperclip

`PAPERCLIP_COMPANY_ID`, `PAPERCLIP_SCANNER_AGENT_ID` и т.д. **не являются секретами**, но привязаны к вашей установке. Храните их в `.env` локально или в runbook команды, не в публичном репозитории без необходимости.
