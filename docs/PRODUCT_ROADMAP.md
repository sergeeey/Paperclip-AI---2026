# Product roadmap — метрики, SARIF, B2B

Документ для следующих итераций после первых реальных сканов.

## Метрики (внедрить после 3–5 сканов)

| Метрика | Определение | Зачем |
|---------|-------------|--------|
| Time-to-report | от принятия задачи до письма клиенту | SLA |
| NIST success rate | доля CVE с успешной верификацией | здоровье пайплайна |
| Client-reported FP | подтверждённые ложные срабатывания | качество правил/промптов |
| Cost per scan | API + инфра на задачу | маржа |

Хранение: таблица в `.paperclip/memory/progress.md` или внешняя BI по мере роста.

## SARIF и CI

- Экспорт результатов semgrep (или иного SAST) в **SARIF 2.1.0**.
- Публикация артефакта в GitHub Actions / GitLab Code Quality для клиентов с собственным CI.
- Зависимость: стабильный путь к бинарю semgrep и версии ruleset.

## B2B / юридический минимум

Перед платными контрактами подготовить (юрист + шаблоны):

- **Ограничение ответственности:** отчёт — оценочное мнение, не сертификация.
- **DPA:** обработка репозитория/метаданных, сроки удаления клонов.
- **Использование ИИ:** раскрытие использования LLM и внешних API (NIST, Brave, почта).
- **SLA:** что происходит при недоступности NIST/провайдеров (`[PENDING_VERIFICATION]`).

Этот репозиторий не заменяет юридическую консультацию.
