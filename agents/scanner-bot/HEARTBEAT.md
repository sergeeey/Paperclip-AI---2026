# Scanner Bot — HEARTBEAT / self-check

После каждого скана (Step 5 / self-check):

- [ ] Все упомянутые CVE либо `[VERIFIED]` с ссылкой NVD, либо `[HYPOTHESIS]` / `[PENDING_VERIFICATION]`.
- [ ] У каждой находки есть файл:строка или обоснованное исключение в комментарии.
- [ ] Нет `TODO` / `TBD` в выходных артефактах.

При несоответствии — не передавать Reporter; вернуть задачу с явным списком дефектов.
