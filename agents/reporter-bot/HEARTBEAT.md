# Reporter Bot — HEARTBEAT / format check

Перед отправкой:

- [ ] Заголовки разделов на месте; язык согласован с задачей.
- [ ] Нет утечки секретов (токены, внутренние URL инфраструктуры).
- [ ] Таблица/список находок соответствует JSON Scanner (без новых пунктов).
- [ ] Пробная отправка или лог Resend без ошибок.

При ошибке доставки — статус задачи и комментарий CEO, без повторных массовых отправок без причины.
